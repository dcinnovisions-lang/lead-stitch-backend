# Outlook OAuth - Cost & Pricing Information

## Short Answer: **FREE** ✅

**No payment is required** for Outlook OAuth integration. Everything you need is available on Azure's free tier.

**Important:** Even after your Azure free trial ($200 credit for 6 months) expires, OAuth app registrations remain **FREE FOREVER** because they're part of Microsoft Entra ID's always-free tier.

## Detailed Cost Breakdown

### 1. Azure Account - FREE ✅

- **Azure Free Account:** Completely free
- **No credit card required** for basic features
- **$200 credit** for first 6 months (not needed for OAuth)
- **Free tier includes:** App registrations, OAuth flows, basic Azure AD features
- **⚠️ IMPORTANT:** After the 6-month trial expires, OAuth app registrations remain **FREE** (part of always-free Microsoft Entra ID tier)

### 2. Azure App Registration - FREE ✅

- **Creating app registrations:** FREE
- **OAuth 2.0 flows:** FREE
- **Client secrets:** FREE
- **Redirect URIs:** FREE
- **API permissions configuration:** FREE

**Cost:** $0.00

### 3. Microsoft Graph API - FREE ✅

- **Mail.Send API calls:** FREE (for reasonable usage)
- **Mail.ReadWrite API calls:** FREE
- **User.Read API calls:** FREE
- **Token refresh:** FREE

**Cost:** $0.00

**Note:** Microsoft Graph API has very generous free limits. Unless you're sending millions of emails per month, you won't hit any paid tiers.

### 4. OAuth Token Storage - FREE ✅

- **Database storage:** Uses your existing database (no additional cost)
- **Token encryption:** Uses your existing encryption (no additional cost)

**Cost:** $0.00

## Microsoft Graph API Limits

Microsoft Graph API has very generous free limits:

- **Throttling:** 10,000 requests per 10 minutes per app (per tenant)
- **For email sending:** This is more than enough for most use cases
- **No per-email charges** for basic usage

**Example:**
- 10,000 requests per 10 minutes = 1,000 requests per minute
- 1,000 requests per minute = 60,000 requests per hour
- 60,000 requests per hour = 1,440,000 requests per day

**Even at 1.4 million emails per day, you're still within free tier!**

## FAQ

### Q: What happens after my 6-month Azure free trial ($200 credit) expires?
**A:** Your OAuth app registrations will continue to work **FOR FREE**! The $200 credit is for Azure services (VMs, storage, etc.), but OAuth app registrations are part of Microsoft Entra ID's **always-free tier** that never expires. You don't need to pay anything for OAuth functionality.

### Q: Do I need to pay for Azure?
**A:** No! Azure free tier is sufficient for OAuth app registrations. Even after the trial expires, OAuth remains free.

### Q: Do I need a credit card?
**A:** No! Basic Azure features (including app registrations) don't require a credit card.

### Q: Will I be charged for sending emails?
**A:** No! Microsoft Graph API is free for reasonable usage. You'd need to send millions of emails per month to hit any paid tiers.

### Q: What if I exceed free limits?
**A:** Very unlikely. Microsoft Graph API has extremely generous free limits (10,000 requests per 10 minutes). Unless you're sending millions of emails, you won't hit limits.

### Q: Can I use this in production?
**A:** Yes! The free tier is production-ready for OAuth integrations.

### Q: Will costs increase over time?
**A:** No! OAuth app registrations and basic Microsoft Graph API usage remain free forever. The always-free tier doesn't expire.

### Q: What if my Azure subscription expires or I cancel it?
**A:** OAuth app registrations will still work! They're part of Microsoft Entra ID (Azure AD), which has a free tier that doesn't require an active Azure subscription. Your app registration will continue functioning.
